# they read a fixture only the owner's machine holds and print a skip where it
# is absent, so on CI they always skip. `make test-machine-local`
# (mk/test-machine-local.sh) runs every target listed here, as `cargo test`
# runs it, once per release, before the tag
# (docs/user/contributing/releases.md).
#
# One line per target: its path from the repo root. A target that prints a
# skip for another cause is exempt through a line that names it:
#   exempt <path>: <reason>

# target under crates/*/tests/ that is not cuda-gated and prints a skip.
